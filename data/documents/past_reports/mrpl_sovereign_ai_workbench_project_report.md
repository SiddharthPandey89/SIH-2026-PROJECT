# MRPL Sovereign On-Premise Agentic AI Workbench
## Project Progress Report

**Organization:** Mangalore Refinery and Petrochemicals Limited (MRPL)  
**Theme:** Smart Automation  
**Report Type:** Project progress and capability summary

## 1. Executive Summary

The MRPL Sovereign On-Premise Agentic AI Workbench is being developed as a secure, offline-first platform for using artificial intelligence with confidential refinery and petrochemical information. The project brings locally hosted AI models, document intelligence, knowledge retrieval, and agentic task execution into one controlled workbench.

The primary objective is to help authorized MRPL personnel find information quickly, automate repeatable knowledge-work, and generate useful outputs while keeping organizational data inside MRPL-controlled infrastructure.

## 2. Progress Summary

The project has established a modular foundation containing:

- A backend service for chat, agent tasks, document upload, and knowledge-base operations
- Local storage for documents, generated outputs, conversation history, and vector data
- Knowledge-base ingestion for Markdown, text, PDF, and DOCX files
- Retrieval support for manuals, standard operating procedures, and previous reports
- Local model areas for language, embedding, vision, and OCR capabilities
- A workbench interface for chat, agent tasks, uploads, knowledge-base access, outputs, and system monitoring
- Security-focused handling intended for offline and on-premise environments

## 3. Smart Automation Use Cases

The workbench can support the following categories of work:

1. **Knowledge assistance:** Answer questions using approved manuals, procedures, and reports.
2. **Document understanding:** Summarize uploaded documents and identify relevant sections.
3. **Task planning:** Break a user request into smaller steps and coordinate agent execution.
4. **Report support:** Prepare structured drafts and summaries from available source material.
5. **Operational search:** Locate information across multiple internal document collections.
6. **Monitoring:** Provide visibility into workbench, service, and network status.

These capabilities are intended to assist personnel and must remain subject to MRPL procedures, expert review, and formal approval processes.

## 4. Expected Benefits

- Faster access to internal technical and operational knowledge
- Reduced effort for repetitive document and reporting tasks
- More consistent preparation of summaries and draft outputs
- Improved reuse of lessons and information from previous reports
- Greater control over sensitive data than cloud-only AI workflows
- A foundation for future department-specific automation

## 5. Security and Governance Considerations

Because refinery and petrochemical information can be sensitive, the workbench should be operated with the following controls:

- Keep documents, prompts, model processing, and generated outputs within approved infrastructure.
- Restrict access to authorized users and approved knowledge sources.
- Record important agent actions and generated outputs for review.
- Treat AI responses as assistance rather than as a replacement for qualified personnel.
- Require human verification before safety-critical, maintenance, production, compliance, or emergency decisions.
- Review uploaded files and generated reports according to MRPL information-management policies.

## 6. Lessons and Observations

The project demonstrates that a sovereign AI workbench can combine smart automation with stronger control over enterprise data. The most important design requirement is reliable grounding: responses should use relevant, approved internal documents and clearly communicate when supporting information is unavailable.

A second important requirement is operational trust. Users need traceable outputs, predictable workflows, and clear review points before AI-assisted results are used in real operational decisions.

## 7. Recommended Next Steps

- Expand the curated manual, SOP, and past-report collections with approved MRPL material.
- Validate retrieval quality using representative technical and operational questions.
- Add role-based access controls and stronger audit visibility.
- Test document ingestion for scanned PDFs and image-based records.
- Establish evaluation criteria for answer accuracy, source grounding, and response time.
- Conduct pilot reviews with domain experts before production deployment.

## 8. Conclusion

The MRPL Sovereign On-Premise Agentic AI Workbench provides a foundation for secure smart automation. By combining local AI processing with controlled enterprise knowledge, it can help MRPL improve information access and productivity while preserving data sovereignty, operational discipline, and human accountability.
